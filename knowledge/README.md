How marketing works, written for Claude to use, not for you to read. The skills open these files when a job
needs them. Each skill also carries its own core principles, so it still works if a file is missing.

| File | Used by | Covers |
|---|---|---|
| `Hooks_And_Headlines.md` | ads, content, email, landing-page, lead-magnet | Openers and headlines that stop the scroll |
| `Ad_Scripting.md` | ads | How video and static ads are built |
| `Messaging_Psychology.md` | all copy skills | Why people buy, awareness levels, objections |
| `Lead_Magnets.md` | lead-magnet | Free offers that attract the right buyers |
| `Lead_Nurture.md` | email | Turning new leads into customers over email |
| `Content_Engine.md` | content | Organic content that builds trust and gets leads |

You can add your own. Put a `.md` file here, and tell Claude in `CLAUDE.md` or in a skill when to read it.
